# Kwarta - Personal Debt & Lending Tracker

A clean, offline-first personal debt tracker built with Jetpack Compose, Room database, DataStore, and WorkManager.

## Features
- **Strict Philippine Peso (₱) Support**: Standard decimal keypad with tabular numerals.
- **Offline-first Architecture**: Room DB with reactive Flow and encrypted local persistence.
- **Biometric App Lock & Privacy Masking**: Hide financial figures and protect records with biometric authentication.
- **SMS / Messaging Reminders**: Friendly, multi-language (Tagalog/English) customizable debt reminder templates.
- **Timeline Audit Trail**: Track every transaction, partial repayment, and settled balance.
- **CSV Data Export**: Easily export transaction records.
